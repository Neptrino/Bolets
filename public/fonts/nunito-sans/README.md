# Nunito Sans (static instances)

Static TrueType instances of Nunito Sans (Regular 400, Bold 700, ExtraBold 800,
Black 900 and Italic 400) downloaded from Google Fonts on 4 September 2026 for
the server-rendered Instagram cards (`next/og` cannot use the `next/font`
pipeline). Licensed under the SIL Open Font License 1.1, see `OFL.txt`.
