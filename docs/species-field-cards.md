# Species field cards

`data/species-field-card-artwork.ts` maps stable species IDs to approved quality-80 WebP illustrations in `public/media/field-cards/`. These are version-controlled application assets, included in the application image. All 62 current catalogue species have illustrated cards; the generated photographic card remains a fallback for future additions.

The existing `/bolets/[slug]/targeta` route encodes the WebP source as a PNG without further quality loss for downloads and native sharing. Its bounded 384/768-pixel WebP previews remain lazy-loaded. Cache identities include the artwork content hash, so replacements invalidate release-local generated previews. Scientific-name redirects remain supported.

## Release packaging

All 62 active sources are WebPs encoded at quality 80, effort 6, explicitly selected by the user after a full-size comparison. They total 15,911,204 bytes versus 220,967,500 bytes for the PNG masters. Lossless WebP was also measured (115,164,650 bytes), but was not selected. Quality 80 introduces slight fine-texture loss; the original PNG masters remain available locally. Their public filenames use `.webp`; historical PNG filenames above refer to the retained creative masters. The application provides PNG downloads from the compressed source without further loss through the existing serialized content-keyed cache. The 384/768-pixel WebP previews remain unchanged. Both Git source archives and the immutable production image include all cards; PNG masters and revision provenance remain in the local `assets/field-cards/` library.
